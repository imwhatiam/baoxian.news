
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 产品名 / 条款名 / 文号。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代号 / 文号 / 没信息量的 teaser（如 "2026 年第 3 期"、"关于某某的通知"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "关于优化车险费率形成机制的通知" + 来源 "金融监管总局" → "金融监管总局发布通知，优化车险费率形成机制"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体产品时，用上位词（如"一款百万医疗险"）兜底，绝不凭"行业常识"编一个具体产品名 / 条款号 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：解读、分析、盘点、测评、答记者问这类标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的产品、文件或新数据，就改写成“发布 / 推出 / 上线 / 施行”。只有原标题明确宣布了发布、印发、施行或处罚，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、产品、条款名。
   例：原标题 "解读：新会计准则对寿险公司利润的影响" → "新会计准则对寿险公司利润的影响解读"，不能写成 "监管发布新会计准则"。
   例：原标题 "车险综改三年回顾" + 来源和正文明确指向某省 → "某省车险综改三年回顾"，不能只写成缺主体的 "车险综改三年回顾"。
6. 本条的动作和背景里的旧发布要分清：原文把发布写成过去的事（“上周印发”“此前已施行”“去年上线”），本条是在讲影响、做解读或再次提及，标题写解读、分析或回顾，把发布交代成此前的事；不能写成“发布 / 推出 / 施行”，否则读者会当成今天的新闻。只有原文明确某项规则是现在才施行或调整，才对那一项用对应动作。
   例：正文 "去年施行的报行合一政策，正在改变银保渠道的费用结构" → "报行合一施行一年，银保渠道费用结构的变化"，不能写成 "监管推行报行合一"。
